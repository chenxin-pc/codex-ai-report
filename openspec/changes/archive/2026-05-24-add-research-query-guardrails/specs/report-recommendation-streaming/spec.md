## ADDED Requirements

### Requirement: 流式推荐 MUST 遵守投研输入可分析性和输出降级规则

流式推荐接口 MUST 与同步推荐接口使用一致的投研输入可分析性判定和输出降级语义。不可分析输入 MUST 通过流事件返回投研模式引导，并正常结束流。

#### Scenario: 流式接口处理不可分析输入

- **GIVEN** 用户通过流式推荐接口提交“你好”
- **WHEN** 系统处理请求
- **THEN** 系统 MUST 发送表示不可分析或引导状态的事件
- **AND** 系统 MUST 不发送非空证据列表
- **AND** 系统 MUST 不调用模型生成投研长文
- **AND** 系统 MUST 发送 done 事件结束响应

#### Scenario: 流式接口处理主题分析输入

- **GIVEN** 用户通过流式推荐接口提交行业或主题研究问题
- **WHEN** 系统检索到相关证据
- **THEN** 系统 MAY 在证据事件或正文中输出相关公司候选
- **AND** 系统 MUST 说明候选公司与主题的关联依据
- **AND** 系统 MUST 将模型正文限制为主题分析或候选公司说明
- **AND** 系统 MUST 不输出买卖、评级、目标价或仓位建议

#### Scenario: 流式接口处理证据污染

- **GIVEN** 流式推荐召回结果存在多标的混杂
- **WHEN** 系统生成流式正文
- **THEN** 系统 MUST 明确说明证据主体不一致
- **AND** 系统 MUST 不将混杂证据合并为单一公司结论
- **AND** 系统 MUST 发送 done 事件结束响应

#### Scenario: 流式接口处理证据质量失败

- **GIVEN** 流式推荐召回结果存在无证据、低相关、数据指标错配或引用缺失
- **WHEN** 系统生成流式正文
- **THEN** 系统 MUST 明确说明对应降级原因
- **AND** 系统 MUST 不输出高确定性投资建议
- **AND** 系统 MUST 发送 done 事件结束响应

#### Scenario: 流式接口处理 LLM 兜底分类失败

- **GIVEN** 流式推荐输入无法被本地规则高置信判定
- **AND** LLM 兜底分类失败或低置信
- **WHEN** 系统处理请求
- **THEN** 系统 MUST 发送投研模式引导事件
- **AND** 系统 MUST 不发送非空证据列表
- **AND** 系统 MUST 发送 done 事件结束响应
