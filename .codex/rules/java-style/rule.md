# Java 编码规则

## 命名
- 类名 `UpperCamelCase`；方法/变量 `lowerCamelCase`；常量全大写下划线。
- 禁止中文、拼音或无意义缩写命名（极小作用域除外）。
- 抽象类以 `Abstract`/`Base` 开头；异常类以 `Exception` 结尾；枚举类以 `Enum` 结尾。
- Boolean 包装类型字段不要以 `is` 开头。
- 请求 DTO 以 `ReqDTO` 结尾，响应 DTO 以 `RespDTO` 结尾。
- 测试类以被测类名开头并以 `Tests` 结尾。

## 可读性
- 保持 4 空格缩进与现有代码风格，不做无关格式化。
- 禁止魔法值散落，业务含义明确的数值/字符串需提取常量。
- 方法职责单一，复杂编排拆分。
- 优先表达正常路径，减少嵌套，必要时提前返回。

## 面向对象与空值
- Spring Bean 使用构造器注入，不使用字段注入。
- 返回集合优先空集合，不返回 `null`。
- 字符串判空前处理 `null`；对象比较优先非空对象调用 `equals`。
- 精确数值场景使用 `BigDecimal` 或明确误差策略。
- 避免暴露可变集合内部状态。

## 集合与并发
- 已知容量时设置初始容量。
- 增强 `for` 遍历时不直接修改原集合。
- Spring 单例 Bean 禁止保存请求级可变状态。
- 禁止直接使用 `Executors` 创建生产线程池。
- 时间处理统一使用 `java.time`。

## 异常与日志
- 禁止吞异常；需处理、转换或带上下文重抛。
- 禁止 `System.out.println` 与 `printStackTrace`。
- 日志使用占位符，不拼接字符串。
- 日志中禁止输出密钥、密码、敏感信息与完整 OCR 原文。
