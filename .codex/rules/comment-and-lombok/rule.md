# 注释与 Lombok 规则

## 类与方法注释模板（强制）
```java
/**
 * @Description:
 * @Logic:
 * @Param:
 * @Return:
 * @author: cx
 * @Date: yyyy-MM-dd HH:mm:ss
 */
```

## 注释语义要求（强制）
- `@Description` 必须描述真实行为与结果，禁止模板化空话。
- `@Logic` 必须概述核心处理路径与关键分支（如：空值分支、降级分支、异常分支）。
- `@Param` 必须列出主要入参与用途；无入参时写明“无”。
- `@Return` 必须写明返回对象语义；`void` 方法写明“无（仅副作用）”并注明副作用。
- 方法注释应覆盖：做了什么、主要输入对象、核心逻辑、输出或副作用。
- `@Date` 必须填写真实创建/修改时间，不允许留空或占位文本。
- 禁止使用“负责相关业务能力”“按方法或类型既定职责”“详见方法签名”“详见返回类型”“执行 xxx 相关业务处理”等无法说明具体含义的占位注释。

## 类、方法、属性注释覆盖（强制）
- 新增或修改 Java 类、接口、枚举、record 时，必须检查类注释、方法注释、属性注释是否齐全。
- 类注释必须说明该类型在业务链路中的职责，不得只写“负责相关业务能力”。
- 方法注释必须说明入参、返回值、副作用和关键分支；重载方法也必须分别说明兼容或差异点。
- 属性注释必须覆盖普通字段、常量、配置项、枚举值和 record component，说明业务含义、来源、默认值或使用场景。
- 若本次仅调整注释，也需要确保注释与当前代码行为一致，禁止补与实现不符的说明。
- 修改既有 Java 文件时，若发现被修改文件内已有占位注释或明显缺失注释，必须在同一文件范围内同步修正，不得把旧占位注释继续视为合规。

## 方法注释书写时机（强制）
- 新增方法时，必须在实现前或实现后同一提交内补齐方法注释模板字段。
- 修改方法逻辑、入参或返回语义时，必须同步更新对应注释字段。
- 方法中涉及重要业务或复杂业务时，必须在方法体内为关键处理步骤补充注释（说明业务意图、关键判断或分支原因）。
- 复杂方法中的每一行业务代码都必须具备功能描述；功能描述可以是行内注释、上一行注释，或覆盖该行的连续逻辑块注释。
- 空行、括号行、纯格式换行、简单参数透传、显而易见的 getter/setter 不视为需要单独功能描述的业务代码行。

## 存量代码注释任务（强制）
- 用户明确要求“全项目注释”“所有代码注释”“每个类/方法/每行注释”时，必须先审计当前缺口，再按目录或模块分批修复；若无法在单次任务内完成全量修复，必须说明已完成范围、未完成范围和主要阻塞。
- 存量注释修复必须优先覆盖类、接口、枚举、record、方法、构造器、字段、常量和枚举值；逐行注释仅要求覆盖有业务含义的代码行。
- `package`、`import`、注解行、空行、单独括号行、链式调用的纯格式换行、测试断言的显而易见参数换行，不要求单独逐行解释。
- 大规模补注释不得机械填充占位文本；无法准确说明业务含义时，应先阅读调用关系、测试和配置，再补真实注释。

## 规则生效排查（强制）
- 发现注释规则未生效时，优先检查 `AGENTS.md` 是否在 Java 修改路由中加载本规则。
- 其次检查构建校验是否覆盖目标文件；若 Checkstyle、hook 或 CI 仅覆盖部分文件，不能据此判断全项目已满足注释规则。
- 再检查已有注释是否只是模板化占位；占位注释应视为缺失注释处理。

## 字段注释规则（强制）
- 字段注释必须说明实际业务含义与用途。
- 禁止仅写“模型/参数/状态”等空泛词。
- 必要时补充默认值语义或配置来源。

## Lombok 默认策略（强制）
- 默认使用 Lombok 生成 `get/set`，不手写重复访问器。
- 优先使用 `@Getter` / `@Setter` 的最小范围生成。
- 有业务校验、派生逻辑、兼容逻辑时必须手写方法。

## 常用注解
- `@Getter` / `@Setter`：访问器生成。
- `@ToString`：调试输出；敏感字段必须 `exclude`。
- `@EqualsAndHashCode`：值对象相等性；继承场景显式 `callSuper`。
- `@RequiredArgsConstructor`：Spring Bean 构造注入优先。
- `@Builder`：多参数对象构建，DTO/测试优先。
- `@Slf4j`：日志对象生成。
- `@Data`：仅简单数据载体使用，复杂对象慎用。

## 安全限制
- 涉及密码、密钥、Token、证件号等敏感字段时，禁止泄露在 `toString`。
- 新增或调整 Lombok 注解后，必须确保 `mvn -q test` 通过。
